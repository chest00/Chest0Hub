Progresser dans Circuit : relier tout le réseau

Repérer les extrémités

Cherchez A et S, puis les pièces à une seule connexion. Le réseau doit inclure toutes les pièces actives, même celles qui ne semblent pas sur le chemin le plus direct. Les cases noires réduisent les liaisons possibles. Une connexion ne traverse pas une case vide ni une diagonale.

Compter les quarts de tour

Un appui donne un quart de tour horaire. Une pièce droite peut avoir deux orientations visuellement équivalentes ; un virage exige souvent un ou deux appuis. Vérifiez les encoches entre deux actions. Le budget porte sur les rotations réelles, y compris celles jouées par les indices.

Utiliser un indice comme une action

L’indice joue une rotation vers une solution de référence, pas une explication complète. Il coûte un mouvement et réduit le bonus d’indices non utilisés. Il reste utile pour relancer la lecture d’un groupe. Après son action, observez quelle connexion est apparue avant de choisir la suivante.

Mesurer ses progrès

Finir un défi débloque le suivant. Les étoiles dépendent du score ; une victoire à faible budget restant reste une victoire. Vous pouvez rejouer les défis débloqués pour améliorer leur performance. Les rotations en cours sont sauvegardées et peuvent être rejouées au chargement ; un export conserve cette reprise.
